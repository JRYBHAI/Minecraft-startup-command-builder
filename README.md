## ✨ Features

- **Live command output** that updates as you type
- **Server RAM and total PC RAM** inputs, with a safety check so you don't give the server too much memory
- **Server types:** Fabric, Quilt, Paper, Vanilla (`-jar`), and Forge / NeoForge 1.17+ (`user_jvm_args.txt`)
- **Java version aware:** Java 17 (MC 1.18 to 1.20.4), Java 21 (MC 1.20.5+), and Java 24+
- **Garbage collector choice:** Aikar's G1 flags, Basic G1, or Generational ZGC (Java 21+)
- **Windows `start.bat` and Linux / Mac `start.sh`** output with one-click copy
- **"What each flag does"** table so you know exactly what you're running
- **Suggested RAM sizes** and a guide on how to pick one
- Custom Java path, custom jar name/path, and optional extra flags
- Light and dark mode

## 🚀 How to use

1. Open the [live website](https://jrybhai.github.io/Minecraft-startup-command-builder/).
2. Enter your server RAM, total PC RAM, server type, jar name, and Java version.
3. Pick a garbage collector and any options you want.
4. Choose **Windows start.bat** or **Linux / Mac start.sh**.
5. Press **Copy** and paste the command into your start script or server manager.

## 💻 Run locally

```bash
git clone https://github.com/JRYBHAI/Minecraft-startup-command-builder.git
cd Minecraft-startup-command-builder
```

Then open `index.html` in your browser.
